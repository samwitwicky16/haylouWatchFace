# Haylou Watchface Studio 2.0.0

Десктоп-редактор циферблатов **.tbwf** для часов **Haylou RS5** (экран 410×502, `aspectRatio = 0.81673307`, `caseShape = "rectangle"`).
Визуальное редактирование слоёв, живое превью с симуляцией данных, сохранение в чистый JSON внутри zip-контейнера, «запекание» в фон, отмена/повтор, валидация, экспорт PNG.

Всё написано на Python + tkinter, комментарии в коде — по-русски. Установка и запуск описаны в разделе 1, руководство пользователя — в самом конце (раздел 9).

## 1. Установка и запуск

### 1.1. Требования

| Что | Значение |
|---|---|
| ОС | Windows 10/11 (проверено на Windows 11 build 26300) |
| Python | 3.10+ (проверено на 3.12.10, `C:\Python312\python.exe`) |
| Сторонние пакеты | только **Pillow** (проверено на 13.0.0) |
| tkinter | входит в стандартный установщик Python для Windows (проверено на Tk 8.6) |


`requirements.txt` содержит единственную строку `Pillow>=10.0.0`.

Или двойным щелчком по **`run.bat`** (он сам подхватывает `C:\Python312\python.exe`, при другой установке — `python` из PATH; кодировка консоли переключается на UTF-8).

## 2. Что умеет

* Открытие и сохранение **настоящих** .tbwf (zip + `TiBoWaFe.json` + PNG-ресурсы), включая файлы RS4 с предупреждением о другом `aspectRatio`.
* Три заготовки: `empty` (фон + время), `minimal` (время + дата), `full` (все 30 элементов RS5).
* Слои: порядок отрисовки, перетаскивание мышью, ↑/↓, видимость, русские имена элементов.
* Свойства: вид ресурса, источник (файл / папка-секвенция / официальная иконка / шрифт), `size`, `x`/`y`, цвет в трёх представлениях (hex ↔ int32 ↔ пикер), градиент, `sections`, `properties`, `visible`.
* Превью с зумом 25–400 %, вписанием, сеткой и безопасной зоной; клик — выделение, перетаскивание — смена `x`/`y` со снапом к центру.
* Симуляция: «бегущие» часы, шаги/цель/пульс/заряд/калории/дистанция, 16 состояний погоды, ночь, BT, зарядка, демо-режим.
* Ресурсы архива: сетка превью, бейдж «секвенция N», импорт PNG/WebP, извлечение, переименование, удаление, очистка неиспользуемых.
* Undo/redo (лимит 100 снимков), автосохранение каждые 120 с и при закрытии, восстановление после сбоя.
* Валидация по правилам формата, экспорт PNG 410×502 и ×2, «запечь в фон» (анимации → один статичный фоновый слой).

## 4. Почему tkinter/ttk

1. **Ноль зависимостей сверх Pillow.** Задача — рабочий инструмент на локальной машине без интернета; PyQt/PySide потребовали бы ~100 МБ бинарников, customtkinter — ещё один слой поверх tkinter.
2. **Гарантированное наличие.** tkinter идёт в комплекте с Python для Windows, отдельная установка не нужна.
3. **Достаточный набор.** `ttk.Notebook`, `Treeview` (слои), `Scale`/`Spinbox` (свойства), `Canvas` + `PhotoImage` (превью) закрывают весь UI без ручной отрисовки виджетов.
4. **Простая интеграция с PIL.** Отрисовка кадра — один `Image` → `PhotoImage`, обновление по таймеру 40 мс; для 410×502 этого хватает с запасом.
5. **Предсказуемая отладка.** Ошибки в колбэках перехватываются `report_callback_exception` и пишутся в файл — без «молчаливых» падений GUI.
6. **Адаптивность своими руками.** При ширине < 1040 px правая панель уезжает в drawer с затемнением канвы, при ≥ 1040 px — статичные 380 px; на tkinter это 30 строк кода.

## 5. Формат .tbwf: что поддерживается, а что — нет

### 5.1. Как устроен файл

* Zip-архив, внутри — `TiBoWaFe.json` (ключи регистронезависимы) и ресурсы: `/resourceImage/…`, `/resourceCharacter/…`, `/font/…`.
* `aspectRatio`, `caseShape`, `version` — свойства документа; элементы — словарь `имя → объект`.
* Имя элемента = его смысл (`dial`, `hour`, `minute`, `dayOfWeek`, `battery`…), порядок ключей = порядок отрисовки.
* `x`, `y` — нормализованный центр (0..1), `size` — доля ширины экрана; `resourceImage.resource` — файл или папка-секвенция (со слэшем на конце); `sections` — число кадров; `color.colors` — int32 (−1 = белый), `0` = «не перекрашивать».
* Наблюдаемые значения `properties` в образцах: 1, 2, 4, 16, 17, 20, 32, 33, 34, 36, 64, 65, 68; `sections`: 1, 2, 5, 7, 10, 11, 12, 14, 16.

Подробная таблица по 10 образцам — в `docs\format_analysis.md`.

### 5.2. Что формат НЕ поддерживает (проверено по всем 10 файлам)

* **Поворот произвольных слоёв** — полей `rotation`/`angle` нет; вращаются только стрелки `hourHand`/`minuteHand`/`secondHand`, и это делает прошивка.
* **Условий по данным** — нет `condition`/`if`/`opacity`; вместо этого выбирается кадр из `sections` (погода 16, заряд 11, BT 2, goal 11, день недели 7).
* **Анимации по времени** — кроме покадровых секвенций (`sections` кадров в папке), интерполяции нет.
* **Пользовательских SVG и своих иконок** — `resourceIcon.resource` должен быть id из встроенной библиотеки Hello Haylou (30 иконок).
* **Произвольных шрифтов** — только файл в `/font/` с расширением `.ttf` и точным именем, либо системное семейство из списка прошивки.
* **Новых имён слоёв** — ключ = смысл элемента; добавить «свой» слой с произвольным именем нельзя (редактор разрешает, но часы такой слой проигнорируют).
* **Прозрачности на слой** — отдельного поля нет: прозрачность зашита в PNG.
* **Реакции на нажатие** — событий/тапов в формате нет.

Поэтому всё, что редактор умеет «сверх формата» (мигание, условия, демо-данные), либо живёт только в превью, либо переносится в файл через **запекание**: анимация вычисляется, кадр вклеивается в фон, лишние ключи вычищаются (`to_dict(clean=True)` вырезает `_blink`, `_cond`, `_custom_icon` и прочие служебные поля).

## 9. Руководство пользователя

### 9.1. Первый запуск

1. Запустите `run.bat` (или `python main.py`).
2. Окно 1400×900. Слева — превью циферблата, справа — панель на вкладках **Слои / Свойства / Симуляция / Ресурсы**, снизу — статус-бар (разрешение, координаты курсора, число слоёв, «изменено/сохранено»).
3. Если окно уже, чем 1040 px, правая панель превращается в выдвижной ящик — открывайте его кнопкой с тремя полосками на тулбаре или `Ctrl+B`, канва затемняется.
4. Меню **Файл → Новый** даёт три варианта: пустой циферблат (фон + время), минимальный (время + дата), полный набор RS5 (30 элементов).

### 9.2. Открытие и сохранение

* **Файл → Открыть .tbwf…** — обычный диалог; **Файл → Открыть образец из samples…** — список 10 готовых файлов.

### 9.3. Работа со слоями (вкладка «Слои»)

* Список идёт **в порядке отрисовки**: сверху — верхний слой. Рядом с именем ключа показаны русское название, вид ресурса и видимость.

### 9.4. Свойства элемента (вкладка «Свойства»)

1. Выделите слой в списке или кликните по нему в превью.
2. **Вид ресурса**: `resourceImage` / `resourceIcon` / `resourceCharacter` / `font` / `none`. Список ограничен тем, что допустимо для данного имени (подсказывает `catalog`).
3. **Источник**:
   * `resourceImage` — файл PNG из архива или папка-секвенция (со слэшем на конце);
   * `resourceIcon` — выпадающий список 30 официальных иконок с превью 32×32;
   * `resourceCharacter` — папка с кадрами цифр;
   * `font` — системное семейство или файл из `/font/`.
4. **Размер**: `size` (или `font.size`) — спинбокс + слайдер 0.01…1.5, это доля ширины экрана.
5. **Позиция**: `x`, `y` — 0..1 от центра; можно тянуть слой мышью прямо в превью (шаг 1/1000, `Ctrl` — снап).
6. **Цвет**: hex-поле, поле int32 и кнопка пикера `tkinter.colorchooser` синхронизированы. `-1` — белый, `0` — «не перекрашивать». Здесь же тип градиента (`solid` / `linear_vertical`) и до трёх цветов с позициями.
7. **`sections`** — число кадров 1..64 (для погоды 16, заряда 11, BT 2, goal 11, дня недели 7).
8. **`properties`** — список наблюдаемых значений с галочками плюс ручной ввод произвольного целого ≥ 0.
9. **`visible`** — галочка видимости.

Каждое изменение сразу видно в превью и попадает в стек отмены (одна запись на законченное действие).
